Optional synchronization

Local service and private connectivity

The service binds to loopback by default. Non-loopback binding requires a strong API key and an explicit private-network decision.

Local only

Use 127.0.0.1 for the smallest network surface. Data remains on one computer.

Private LAN

Bind deliberately, require an API key, restrict firewall access, and never forward the port from a public router.

SSH tunnel

Forward a loopback service through OpenSSH with persistent known-host verification. A changed key stops the connection.

Container launch

docker compose up --build -d

Set HAIR_API_KEY through a private environment source before any non-loopback deployment. Do not commit it.

Security boundaries
  • HTTP is suitable only for loopback or a separately protected private network.
  • SSH passwords are not accepted by the desktop connection workflow. Use a key and persistent known-host verification.
  • This website cannot connect to or control the installed service without an explicit browser request and compatible local CORS settings.
