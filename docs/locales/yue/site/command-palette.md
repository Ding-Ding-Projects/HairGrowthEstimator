# 指令面板

## 行為

範本喺 `#command-palette` 宣告指令面板、喺 `#palette-search` 宣告索引欄、喺 `#palette-results` 宣告結果清單，並喺 `#palette-size` 宣告卡片或者全視窗尺寸選擇。`Ctrl+Shift+F` 同前置畫面指令按鈕必須開啟同一個面板。

完整面板會索引每個目的地、文章、指令、設定、外觀控制同相關清單操作。目前個人詞彙項目包括分開嘅上載、取代、清除同 `vocabulary-status` 目的地，而 School 模式啟用時，結果會移除全部四項。設定結果會顯示真正可操作嘅即時控制。啟用目的地會選擇所屬分頁同群組、顯示精確元素、捲動到可見位置、聚焦，然後短暫突出顯示，唔使使用者入到頁面仲要玩尋寶。

## 設定

面板尺寸會按訪客持久化，預設係有界限卡片。搜尋預設係純文字，並擁有自己獨立嘅相鄰 regex 工作台。每個結果都帶有穩定 target ID、panel ID、可選 group ID、無障礙內容，以及所使用嘅操作或者設定 binding。

## 失敗情況

- 過時目標必須繼續顯示為不可用結果，唔可以導去附近另一個元素。
- 設定結果唔可以保留第二個可能同設定介面分歧嘅值。
- 快捷鍵衝突或者瀏覽器拒絕時，可見指令按鈕仍然要可用。
- 關閉面板之後，焦點會返去開啟面板嘅元素。

## 安全同私隱

面板唔會索引鎖定認證資料、驗證器秘密、個人詞彙 mappings、自訂圖片 bytes 或私人服務 keys。已鎖定結果會保留鎖定標籤，並開啟正確驗證提示，而唔會繞過鎖定。

## 驗證

原始碼檢查確認咗 `Ctrl+Shift+F`、前置畫面按鈕、固定指令清單、純文字同 regex 搜尋、卡片或者全視窗持久化、目的地導覽、工具子分頁路由、捲動、焦點、短暫突出顯示，以及四個 School 敏感個人詞彙目的地。個人詞彙面板同狀態錨點嘅聚焦原始碼 fixture 曾經變紅 1 項，還原後通過 1 項。目前固定清單唔係完整索引，結果列只係標籤同開啟按鈕，唔係即時豐富設定控制，而已鎖定目標導覽仍然需要直接證明。完整索引、豐富控制、完整本地化、聚焦無障礙行為同建置成品證據仍然待辦。
