# 無障礙同響應式版面

## 行為

網站必須由約 320 CSS pixels 起正常運作，頁面主體唔可以出現橫向捲動。鍵盤使用者會見到清楚焦點、語義名稱同狀態，亦有完整互動路徑。觸控目標符合平台最低尺寸。動作會尊重減少動態效果偏好。螢幕閱讀器會收到有意義嘅標題、區域、即時狀態、分頁方向、結果數量同進度文字。

每個設定控制都要有明確無障礙名稱。外圍卡片標題或者附近段落，唔可以代替輸入欄、select、range、顏色控制或者檔案選擇器本身嘅程式化標籤。

主要、Tools 同 Settings 導覽每次都會設定完整 tab 同 tabpanel 關係。每個分頁引用自己嘅面板，每個面板引用自己嘅分頁，而每個分頁清單只使用一個 `tabindex="0"` 游走焦點目標。方向鍵會跟隨清單方向，Home 同 End 就移去第一個同最後一個已啟用分頁。如果篩選移除目前游走焦點目標，焦點會移去第一個剩低分頁，但唔會改變已選目的地。只有使用者刻意啟用先會改變選擇。

元素內容選單支援 Arrow、Home、End、Enter、Space 同 Escape。關閉選單之後，焦點會返去開啟選單嘅元素，除非所選操作開咗另一個而家接管焦點嘅介面。文件搜尋結果使用具備 option 語義嘅單選 listbox。篩選或者首次顯示唔會移動文章焦點。只有讀者刻意啟用結果之後，焦點先會移去文章。

## 設定

必須有 viewport meta tag。闊表格、程式碼區塊、圖表同工作台範例會喺自己容器內捲動。覆疊層保持喺畫面範圍內，繪製不透明表面，並喺內部捲動。浮動面板支援有界限縮放、適用時拖曳、鍵盤移動同重設。

每個獨立選擇目標最少係 44 × 44 CSS pixels，包括 checkbox、radio button、range、顏色輸入同可見檔案輸入。只有當較細嘅原生控制包含喺更大、有標籤嘅目標入面，而該目標提供完整點擊範圍並保留同一個無障礙名稱，先至可以接受。

## 失敗情況

- 雙語標籤通常最長，可能揭露英文介面睇唔到嘅裁切問題。
- 將桌面瀏覽器縮窄，唔代表已證明觸控行為。
- 只喺 hover 出現嘅操作，需要有點按同鍵盤對應方式。
- 垂直分頁列必須使用垂直方向，同埋向上或向下導覽。
- 篩選分頁清單唔可以將游走焦點留喺已經唔可用嘅分頁，亦唔可以暗中改變已選面板。
- 內容選單關閉時如果冇還原焦點，鍵盤使用者可能會被丟咗去文件根節點，成個人突然失蹤。
- 每次搜尋之後自動聚焦第一篇文件文章，會打斷閱讀，亦唔算刻意啟用。
- 視覺上好大張嘅卡片，唔會自動放大未包裝嘅 checkbox、radio button、range、顏色輸入或者檔案輸入點擊目標。
- 減少動態效果必須停止持續彩虹同非必要時間軸動畫。

## 安全同私隱

無障礙行為唔可以透過無障礙名稱、即時區域或者已複製診斷文字洩露秘密。只有使用者所選操作確實需要時，先顯示本機檔案路徑。

## 驗證

原始碼包括響應式斷點、可見焦點、減少動態效果處理、`forced-colors` media 邊界、`SETTING_CONTROL_NAMES` 同 `applyExplicitSettingNames`、完整 Tools 同 Settings tab 同 tabpanel 關係、共用 `activateManagedTab` 同 `handleManagedTabKeydown` 路徑、篩選後安全游走焦點而唔改變選擇、文件 listbox 同 option 語義、刻意結果啟用處理器、`#docs-article[tabindex="-1"]`，以及帶有 Arrow、Home、End、Enter、Space、Escape 同開啟者焦點返回嘅 `closeContextMenu`。一般輸入最少高 3 rem，checkbox、radio 同 range 目標最少高 2.75 rem，而窄版面會保留探索搜尋同導覽列操作並維持可用，唔會純粹視覺隱藏。聚焦原始碼檢查 `accessibility repair boundaries are explicit and responsive controls remain operable` 喺文章焦點目標缺少 `tabindex="-1"` 時曾經刻意變紅，還原後就通過，屬於三項檢查結果之一，總計 0 項失敗、0 項略過。真正手機同平板闊度、兩種方向、大字體、100、125、150 同 200 percent 縮放、純鍵盤使用、螢幕閱讀器語義、實測對比度、forced-colors 互動、觸控、行為檢查同建置後網站畫面擷取仍然待辦。

部分負面回歸覆蓋包括刻意移除前置畫面來源資料 identifier、一個目前分頁列 regex-builder 註冊，以及文件文章嘅 `tabindex="-1"` 焦點邊界。佢仍未透過刻意移除證明完整無障礙清單、每個設定標籤、巢狀分頁語義、篩選後游走焦點、內容選單導覽、文件 listbox 行為或者每個觸控目標邊界。
