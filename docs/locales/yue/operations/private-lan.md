# 私人 LAN 託管

## 行為

私人 LAN 模式容許同一個私人網絡上另一部受信任裝置連接頭髮生長服務。呢個模式要主動開啟。服務必須綁定到非 loopback 位址，而容器連接埠亦必須喺明確揀選嘅私人介面上發佈。

## 設定

將 `HAIR_HOST` 設成預定嘅容器綁定位址，並提供強健嘅 `HAIR_API_KEY`。喺 Compose 入面，將 `HAIR_PUBLISH_ADDRESS` 設成精確主機端私人位址，唔好沿用預設 loopback 值。只有瀏覽器用戶端需要已知精確來源時，先設定 `HAIR_CORS_ORIGINS`。

## 失敗情況

- 缺少或者太短嘅 API 金鑰會阻止非 loopback 啟動。
- 防火牆規則可能阻擋已發佈連接埠。
- 網絡位址變更後，已儲存嘅直接 URL 可能會失效。
- 綁定範圍太闊會令健康狀態同版本路由暴露畀預定介面以外嘅位置。
- CORS 設定保護唔到非瀏覽器用戶端，亦唔可以取代 API 金鑰。

## 安全同私隱

只可以喺私人而且受信任嘅網絡使用呢個模式。唔好將服務直接發佈到公共互聯網。如果伺服器主機唔喺同一個受信任網絡區段，應該優先使用 SSH 通道。絕對唔好將認證資料嵌入伺服器 URL，亦唔好將佢哋提交到 Compose 檔案。

## 驗證

原始碼檢查確認咗 API 金鑰啟動要求同精確來源 CORS。即時主機身份、介面綁定、防火牆可達性、驗證拒絕，以及端到端桌面同步仍然待辦。
