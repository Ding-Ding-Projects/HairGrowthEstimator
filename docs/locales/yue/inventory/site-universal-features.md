# 網站通用功能清單

## 範圍同證據規則

呢份係公開網站畫面嘅人手完整性清單。佢刻意唔會由目前原始碼搵到嘅控制項自動生成，因為只靠探索嘅清單，偵測唔到一個完全消失嘅功能。

目前檢查嘅原始碼邊界包括 `site/index.template.html`、`site/styles.css`、`site/state-contract.js`、`site/security-contract.js`、`site/localization-contract.js`、`site/presentation-contract.js`、`site/regex-client.js`、`site/regex-worker.js`、`site/app.js`、三份 `site/locales/yue` catalogs，同 `scripts/compose-site.mjs`。嚴格 security contract、localization 同 presentation contracts、可棄置 Worker modules、有效 application consumers、accessibility repair functions、有界限 terminal-transfer reader，同 runtime installer validator，都喺以下記錄嘅 anchors 存在原始碼。原始碼已實作代表精確 function 同 registration 存在，但唔代表已經操作過組合後嘅成品。聚焦測試涵蓋連結到 `tests/site/correctness.test.mjs` 嘅四行 correctness 記錄。最後三項 accessibility 同 installer subset 亦有已接受嘅先紅後綠證明。其他聚焦測試、互動 ledgers、畫面擷取同公開部署證明仍然待辦。

負向回歸證據只係部分完成。已接受嘅證據會逐一點名每個曾經刻意移除並觀察到失敗嘅精確邊界。佢永遠唔會將呢啲例子升格成所有清單行、本地化邊界、互動記錄或者畫面擷取記錄都有自己先紅後綠回歸嘅證明。

人手編寫嘅 L06 原始碼邊界已完成本地化：250 個 `ui-core`、274 個 `ui-settings` 同 686 個 `runtime` entries，另加 50 組英文同廣東話文章。五個聚焦本地化測試已通過，而精確 catalog-entry deletion 同 article-locale omission regressions 亦曾經轉紅。以下仍然將本地化寫成待辦嘅行，係指組合後互動、個別行為或者畫面擷取證明，唔係缺少原始碼 catalog entry。原始碼完整唔會關閉任何建置證據行。

每一行都記錄以下邊界：

- **實作** 連結目前原始碼擁有者，並點名佢精確嘅 selector 或 module。"原始碼部分完成" 代表有部分行為存在，但完整合約未實作。
- **本地化** 點名文案擁有者，或者記錄本地化資源缺少。
- **持久保存** 點名瀏覽器或者產品 storage，並將未驗證嘅 key 標記為待辦。
- **聚焦測試 ID** 係未來聚焦套件必須採用嘅穩定識別碼。識別碼唔代表測試已經存在。
- **互動證明** 同 **畫面擷取證明** 係未來必需嘅成品路徑。每一份都會保持待辦，直至由建置成品產生。
