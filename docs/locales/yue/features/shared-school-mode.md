# 共用 School mode

## 行為

School mode 會喺共用本機程式資料區使用一份有版本紀錄。程式執行期間會監察開關狀態、用戶揀選顯示名稱同解鎖參照，所以其他本機程式作出有效變更之後唔需要重新啟動。

開啟模式會保留程式原本語言同搞笑程度選擇。啟用期間，程式會使用認真英文，並喺所有畫面移除粵語、雙語、搞笑程度、個人詞彙同點心控制、路徑、搜尋結果、文件項目、預覽同代號變更。成功本機解鎖再關閉模式之後，先會還原保存選擇。

主程序用 `createSchoolEffectiveState` 同 `reconcileSchoolRecordRead` 協調每次共用紀錄讀取。有效初始紀錄會成為可信基準。如果冇有效基準，實際狀態會保持受限制，並報告降級不可用狀態。之後無效或者不可用讀取會保留上一個有效實際狀態，唔會改成關閉預設。

協調結果包含保留嘅 `record`、`effectiveEnabled`、`status`、`availability`、`degraded`、`reason`、`publishable`、`verifiedDisable` 同 `retainedLastValid` 欄位。`publishable` 代表新讀取候選已獲接受，唔代表要收埋狀態信封。只有呼叫者提供已驗證關閉證據，啟用轉關閉候選先會獲接受。亦只有呢個接受轉換會把 `verifiedDisable` 設成 `true`，畫面先可以還原隱藏偏好。

## 設定

共用紀錄使用有界限版本結構，包括開關狀態、已驗證顯示名稱、單調修訂同時間，以及一個不透明解鎖參照。程式會即時監察共用本機紀錄，讀取或者驗證失敗時保留上一個有效實際狀態。

## 解鎖同復原

PIN 同密碼登記都可以使用。憑證雜湊由作業系統保護，共用紀錄只包含不透明參照。五次錯誤會加入有界限延遲。Passkey 喺嚴格核心結構中有表示，但呢個版本未內置作業系統 passkey 登記配接器，所以選擇器會顯示不可用。

呢個只係介面便利，唔係安全邊界。用戶可以刻意刪除共用本機紀錄重設。

## 失敗情況

無效 Unicode 名稱、空白名稱、過大紀錄、未知欄位、過時時間、不支援解鎖政策、欠缺登記證據同目前憑證唔相符都會被拒絕，而且唔會改變共用展示紀錄。程式會先驗證顯示名稱，之後先保存新憑證。無效、讀唔到、過時、修訂衝突或者未驗證關閉觀察會保留上一個有效狀態，並報告指定降級原因。降級觀察永遠唔會批准還原偏好。

## 安全同私隱

模式只係介面便利，唔會聲稱加密或者防止同一部電腦其他人使用。憑證資料留喺作業系統保護儲存。共用紀錄、記錄、匯出、畫面擷取同原始碼都唔會包含 PIN、密碼、私人詞彙內容或者可用驗證值。

## 驗證

執行 `node --test tests/core/school-mode.test.js tests/core/school-mode-fail-closed.test.js tests/core/presentation-wave-integration.test.js tests/core/vocabulary-integration.test.js`。

## 香港粵語

School mode 用一份本機共用紀錄，開關、改名同解鎖參考會即時監察，其他本機應用做咗有效變更就唔使重新開機。開啟時會保存原本語言同搞笑程度，轉用認真英文，並由畫面、搜尋、文件、預覽同指令清單移除受限制內容。驗證後關閉，就會還原之前選擇。

共用紀錄讀取失敗、格式無效或者暫時攞唔到時，程式會保留上一份有效狀態，唔會突然當成已關閉就放返隱藏選項出嚟。若果連有效基準都未有，畫面會保持受限制，並清楚標示降級同無法讀取。只有經驗證並正式接受嘅關閉轉換，先會發出可還原偏好設定嘅訊號，唔會見到個 `false` 就即刻開閘放人。

PIN 同密碼已經可用。Passkey 資料格式已經有嚴格驗證，但今個版本未附作業系統註冊介面，所以會清楚顯示未可用，唔會整個假掣扮有料。
