# 厘米同英寸

## 行為

厘米係正式儲存單位。Profile 會記錄 `cm` 或 `in` 其中一個顯示偏好。精確轉換合約係 1 inch 等於 2.54 centimetres。

HTTP 服務永遠以厘米驗證長度同生長率。任何唔係 `in` 嘅顯示單位值都會正規化成 `cm`。瀏覽器原始碼用精確乘以 2.54 將英寸轉成厘米，再用乘以 `1 / 2.54` 將厘米轉成英寸。程式儲存正式厘米值，只會將表單同結果嘅顯示值四捨五入至兩個小數位，數字唔會坐轉換旋轉木馬愈轉愈歪。

## 設定

偏好單位儲存喺 `profile.displayUnit`。完整 client 只可以喺呈現同輸入邊界做轉換，儲存時保留正式厘米值，並避免累積轉換漂移。

## 失敗情況

- 無效數值會由服務回傳 HTTP 400。
- 超過 300 厘米嘅值會被拒絕。
- 如果 client 不斷將已四捨五入嘅顯示值轉返正式儲存值，數值可以慢慢漂移。規劃中嘅 client 必須一直保留正式值。
- 符合地區習慣嘅數字輸入同顯示格式仍然有待完成。目前瀏覽器原始碼用固定兩個小數位字串顯示數值。

## 安全同私隱

單位轉換只係本機運算，唔需要網絡請求。量度值跟從 profile 紀錄相同嘅私隱邊界。

## 驗證

原始碼檢查確認以厘米作正式儲存、瀏覽器原始碼使用精確 2.54 轉換，以及 `cm` 或 `in` 偏好。來回轉換穩定性、兩種顯示模式、邊界值、重複切換單位，同本地化數字格式嘅測試仍然有待完成。
