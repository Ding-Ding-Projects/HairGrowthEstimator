# 注意力介面輔助

## 行為

五項介面輔助各自保存，預設全部關閉：

- 聚焦會淡化非目前區域，但唔會收埋內容。
- 低刺激會減少顏色、動態、短暫資料提示同旁白。
- 時間提示會顯示工作階段經過時間同上次有意義變更之後嘅時間。
- 一次一件事會保存一項由用戶揀選嘅下一步。
- 動力提示會喺 40 分鐘冇變更之後出現，揀選遲啲先會安靜一小時。

呢啲只係介面輔助，唔會診斷、評估、提供建議、計分、排名、計連勝，亦唔會聲稱有醫療效益。

作業系統減少動態偏好會獨立停止編排進度同固定彩虹色彩，唔會偷偷開啟低刺激色彩或者通知抑制。

## 設定

每項輔助都係獨立保存嘅布林值，預設關閉。下一步係有長度上限嘅用戶文字。動力提示採用 40 個實際分鐘作為閒置門檻，並提供一小時暫停。減少動態仍然係作業系統偏好，呢啲控制唔會覆寫佢。

## 失敗情況

無效時間會回復至有界限嘅目前時間預設。未來時間唔會產生負數經過時間。下一步會修剪並限制長度。動力提示暫停只接受有界限時段，亦唔會重設其餘四項輔助。

## 安全同私隱

所有輔助狀態只留喺本機。功能唔會推斷診斷、透過網絡傳送活動資料、計算分數，亦唔會經通知或者匯出暴露私人工作內容。

## 香港粵語

聚焦、低刺激、時間提示、一次一件事同動力提示可以獨立開關，預設全部關閉。聚焦只會淡化，唔會收藏內容。低刺激會收靜顏色、動態、非必要提示同旁白。時間提示只報實際分鐘，唔會催你。一次一件事保存由你揀嘅下一步。動力提示喺 40 分鐘冇變更後出現，按「遲啲先」就安靜一個鐘。

呢啲只係介面輔助，唔做診斷、評估、建議、分數、排名或者連勝紀錄。
