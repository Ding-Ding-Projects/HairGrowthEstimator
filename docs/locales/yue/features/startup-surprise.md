# 啟動小驚喜

## 行為

首次執行之後，程式每次啟動會做一次新嘅加密亂數抽選。由 0 包含在內至細過 0.1 嘅值會揀中驚喜，正正係正規化範圍嘅 10 percent。一次啟動永遠唔會抽兩次。

卡片唔會阻塞、唔會搶焦點、唔會出聲，八秒之後會自己收起。首次執行、School mode、錯誤路徑、更新程序、進行中工作同低刺激展示期間都會抑制。

## 設定

抽選機率同八秒展示時間係固定產品行為，冇關閉開關。作用中語言模式同搞笑程度只會改變外圍文字語氣，菜式名稱同公開目錄識別會保持事實。

## 公開圖片邊界

菜式資料係公開目錄紀錄 `hk-dish-0001`，Classic Har Gow · 蝦餃。圖片只會由已發布 `catalog-v1` 發佈資產取得。程式會驗證為有界限 PNG，之後先快取喺私人程式資料。呢個 repository 唔會提交任何點心圖片，離線又冇快取時亦唔會顯示替代圖片或者假成功。

## 失敗情況

無效抽選、重複抽選、欠缺公開資產、格式錯誤圖片、網絡不可用、冇快取或者任何作用中抑制條件都會令驚喜唔出現。啟動會照常繼續，亦唔會報告冇發生嘅顯示。

## 安全同私隱

功能冇分析或者追蹤，只會取得固定已發布目錄資產，驗證後先快取，亦唔會保存用戶紀錄、帳戶識別、憑證或者行為歷史。

## 驗證

執行 `node --test tests/core/delight-attention.test.js tests/core/presentation-wave-integration.test.js`。

## 香港粵語

首次啟動之後，每次開應用只會抽一次加密亂數。由 0 開始到細過 0.1 就中，正正係一成範圍，唔會一開機抽幾次增加中獎率。卡片唔阻住開機、唔搶焦點、冇聲，八秒後自己收工。首次啟動、School mode、錯誤、更新、工作進行中同低刺激顯示期間都唔會出現。

相片只會由公開目錄已發布資產取得，通過 PNG 格式同大小驗證先放入私人快取。離線又冇快取就唔顯示，唔會用假相頂住個位。
