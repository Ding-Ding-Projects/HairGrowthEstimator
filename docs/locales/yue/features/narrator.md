# 旁白聲線同速度

## 行為

旁白預設關閉。英文同粵語有獨立已安裝聲線選擇器，每個都用平台聲線嘅穩定 `voiceURI` 做識別。每個選擇器都有自動選項，延遲列出聲線之後會重新整理，會保留已保存但已經冇安裝嘅聲線，亦會報告實際後備聲線。網絡聲線會有清楚標示，因為離線時可能冇聲。

雙語旁白會先英文後粵語排隊。佇列會用新事件取代已過時但未播放嘅事件，唔會疊住重複內容。每個類別有冷卻時間限制普通重複，但錯誤唔會畀冷卻時間收埋。速度限制係 0.1 至 10，音調限制係 0 至 2。

## 設定

旁白有明確開關、每種語言一個穩定聲線選擇、自動後備選項、有界限速度同音調、語言次序，以及同低刺激同輔助技術狀態嘅安靜整合。設定只喺本機保存，預設唔會硬寫任何已安裝聲線名稱。

## 無障礙共存

主程序會報告作業系統無障礙支援狀態，並把變更送畀畫面。當呢個訊號或者用戶保存嘅輔助技術安靜訊號啟動時，旁白會取消並暫停。低刺激模式亦會抑制旁白。

## 失敗情況

介面會分清楚載入中、某語言冇聲線、已選聲線存在、已選聲線未安裝、網絡後備聲線同語音合成不可用。某種語言冇聲線只會停嗰種語言，唔會聲稱已經讀出。

## 安全同私隱

旁白只會收到最後揀選嘅有界限文字。聲線識別同設定只留喺本機。佇列唔會把文字、聲線資料、憑證、私人路徑或者程式紀錄送去項目服務。

## 驗證

執行 `node --test tests/core/narrator.test.js tests/core/presentation-wave-integration.test.js`。

## 香港粵語

旁白預設關閉。英文同粵語各自揀已安裝聲線，用穩定 `voiceURI` 保存，聲線清單遲到都會再更新。已保存聲線唔見咗唔會偷偷重設，介面會保留選擇同講清楚實際後備聲線。雙語會先英文後粵語排隊講，重複舊訊息會換走，唔會疊到成條聲音塞車。

作業系統無障礙支援啟動，或者用戶開咗輔助技術安靜訊號時，旁白會立即停止同暫停。冇適合聲線就老實講，唔會靜雞雞扮讀完。
